Section 01
Descriptive Statistics
Mean (Arithmetic Average)
x̄ = (Σxᵢ) / n
Legend
x̄Sample mean (pronounced "x-bar")
ΣxᵢSum of all individual data values
nNumber of data points in the sample
Sample Variance
s² = Σ(xᵢ − x̄)² / (n − 1)
Legend
s²Sample variance
xᵢ − x̄Deviation of each value from the mean
n − 1Degrees of freedom (use n-1 for sample, n for population)
⚠️
Use n − 1 for sample; use n for population (σ²). Using wrong denominator is the #1 exam error.
Standard Deviation
s = √[ Σ(xᵢ − x̄)² / (n − 1) ]
Legend
sSample standard deviation (same units as data)
σPopulation standard deviation (√(Σ(xᵢ − μ)²/N))
Coefficient of Variation (CV)
CV = (s / x̄) × 100 %
Legend
CVRelative variability as a percentage — allows comparison across different units
💡
Lower CV = more consistent data. Use to compare consistency across datasets with different means.
Quartiles & IQR
IQR = Q3 − Q1
Lower Fence = Q1 − 1.5 × IQR
Upper Fence = Q3 + 1.5 × IQR
Legend
Q125th percentile (lower quartile)
Q375th percentile (upper quartile)
IQRInterquartile range — spread of middle 50%
🪤
Outlier = any data point outside the fences. Always sort data first before computing quartiles!
Skewness Detection
Right Skew:  Mean > Median > Mode
Symmetric:  Mean = Median = Mode
Left Skew:   Mean < Median < Mode
💡
Mean is pulled toward the tail. The tail tells you the direction of skew.
🎲
Section 02
Probability
Classical Probability
P(A) = n(A) / n(S)
Legend
P(A)Probability of event A
n(A)Number of favorable outcomes
n(S)Total number of equally likely outcomes (sample space)
Addition Rule (Union)
P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
Legend
∪Union — A or B (or both) happen
∩Intersection — both A and B happen
✅
If mutually exclusive: P(A ∩ B) = 0, so P(A ∪ B) = P(A) + P(B)
Conditional Probability
P(A | B) = P(A ∩ B) / P(B)
Legend
P(A|B)Probability of A given that B has already occurred
💡
For independent events: P(A|B) = P(A) — knowing B gives no info about A.
Independence Rule
P(A ∩ B) = P(A) × P(B)  [if independent]
P(Aᶜ ∩ Bᶜ) = P(Aᶜ) × P(Bᶜ) = (1−P(A))(1−P(B))
🪤
Independent ≠ Mutually Exclusive! Independent: P(A∩B)=P(A)P(B)≠0. Mutually Exclusive: P(A∩B)=0.
Bayes' Theorem
P(A|B) = P(B|A)·P(A) / P(B)
P(B) = P(B|A)·P(A) + P(B|Aᶜ)·P(Aᶜ)
Legend
P(A)Prior probability of A
P(B|A)Likelihood — probability of evidence B given A
P(A|B)Posterior — updated probability of A given evidence B
Naïve Bayes Classifier
P(Class | x₁,x₂,...,xₙ) ∝
  P(Class) × ∏ P(xᵢ | Class)
Legend
∝Proportional to (we pick the class with highest value)
∏Product over all features (assumes feature independence)
⚠️
Apply Laplace Smoothing (+1 to counts) if any feature probability = 0.
Combinations & Permutations
C(n,r) = n! / [r!(n−r)!]
P(n,r) = n! / (n−r)!
Legend
C(n,r)Choose r from n — ORDER doesn't matter
P(n,r)Arrange r from n — ORDER matters
🎯
Section 03
Discrete Probability Distributions
PMF Validity Conditions
Σ P(X = x) = 1  for all x
0 ≤ P(X = x) ≤ 1
💡
A PMF is valid only if probabilities are non-negative AND sum to exactly 1. Use this to find unknown constant k.
Expected Value (Mean) E[X]
E[X] = μ = Σ x · P(X = x)
Legend
E[X]Expected value = long-run average of X
xEach possible value X can take
P(X=x)Probability X equals that value
Variance of X
Var(X) = E[X²] − (E[X])²
E[X²] = Σ x² · P(X = x)
Legend
Var(X)Variance = average squared deviation from mean
Linear Transform of X
E[aX + b] = a·E[X] + b
Var(aX + b) = a²·Var(X)
Legend
a, bConstants (b shifts the distribution, a scales it)
🪤
Variance of (aX+b): the constant b disappears! Only a² remains. Students often forget to square a.
Binomial Distribution
P(X = k) = C(n,k) · pᵏ · (1−p)ⁿ⁻ᵏ
μ = np  |  σ² = np(1−p)  |  σ = √(np(1−p))
Legend
nNumber of independent trials
pProbability of success on a single trial
kNumber of successes you want to find probability for
C(n,k)Binomial coefficient — ways to arrange k successes in n trials
💡
Conditions: Fixed n trials, each trial independent, constant p, only 2 outcomes (success/failure).
Poisson Distribution
P(X = k) = (λᵏ · e⁻λ) / k!
μ = λ  |  σ² = λ  |  σ = √λ
Legend
λAverage rate of events per unit time/space (lambda)
eEuler's number ≈ 2.71828
k!k factorial (k × (k-1) × ... × 1)
💡
Poisson approximates Binomial when n is large and p is small: λ = np.
Joint PMF (Discrete)
P(X=x, Y=y) — given in a table
Marginal X: P(X=x) = Σᵧ P(X=x, Y=y)
Marginal Y: P(Y=y) = Σₓ P(X=x, Y=y)
Conditional: P(X=x|Y=y) = P(X=x,Y=y)/P(Y=y)
💡
X and Y are independent iff P(X=x,Y=y) = P(X=x)·P(Y=y) for ALL combinations.
〜
Section 04
Continuous Probability Distributions
PDF Validity Conditions
∫ f(x) dx = 1  (over all x)
f(x) ≥ 0 for all x
💡
For continuous distributions, P(X = exact value) = 0. We only talk about probabilities over intervals: P(a ≤ X ≤ b) = ∫ₐᵇ f(x) dx.
Continuous E[X] and Var(X)
E[X] = ∫ x · f(x) dx
E[X²] = ∫ x² · f(x) dx
Var(X) = E[X²] − (E[X])²
Uniform Distribution U(a, b)
f(x) = 1/(b−a)  for a ≤ x ≤ b
μ = (a+b)/2  |  σ² = (b−a)²/12
Legend
a, bLower and upper bounds of the uniform distribution
Normal Distribution N(μ, σ²)
f(x) = (1/σ√(2π)) · e^(−(x−μ)²/2σ²)
Z = (x − μ) / σ   [standardise]
Legend
μPopulation mean (centre of the bell)
σPopulation standard deviation (spread/width)
ZStandard normal variable — N(0,1)
💡
68–95–99.7 rule: ±1σ=68%, ±2σ=95%, ±3σ=99.7% of data.
Normal Approximation to Binomial
μ = np  |  σ = √(np(1−p))
Z = (x ± 0.5 − np) / √(np(1−p))
Legend
±0.5Continuity correction (+0.5 for ≤, −0.5 for ≥)
⚠️
Use when n is large (n≥30). Apply continuity correction: P(X < k) → P(X < k − 0.5).
Joint Continuous PDF
∫∫ f(x,y) dx dy = 1
f_X(x) = ∫ f(x,y) dy  [Marginal of X]
f_Y(y) = ∫ f(x,y) dx  [Marginal of Y]
Independent if f(x,y) = f_X(x)·f_Y(y)
🔬
Section 05
Sampling Theory & Central Limit Theorem
Standard Error of the Mean
SE = σ / √n   (or s/√n for sample)
Legend
SEStandard Error — how much the sample mean varies from sample to sample
σPopulation standard deviation
nSample size — larger n → smaller SE → more precise
Central Limit Theorem (CLT)
x̄ ~ N(μ, σ²/n)  as n → ∞
Z = (x̄ − μ) / (σ/√n)
Legend
x̄Sample mean of n observations
μTrue population mean
💡
Works for ANY population shape if n ≥ 30. If population is already Normal, CLT holds for any n.
Sample Size Formula (Margin of Error)
n = (z · σ / ME)²
Legend
MEDesired margin of error (half-width of CI)
zCritical z-value for confidence level (e.g., 1.96 for 95%)
σKnown or estimated population standard deviation
⚠️
Always round UP to the next whole number for sample size.
Confidence Interval for Mean (σ known)
CI:  x̄ ± z_(α/2) · (σ/√n)
Common z-values
90%z = 1.645
95%z = 1.96
99%z = 2.576
Confidence Interval for Mean (σ unknown)
CI:  x̄ ± t_(α/2, n−1) · (s/√n)
Legend
t_(α/2, n−1)t-critical value with df = n−1 (from t-table)
sSample standard deviation
⚠️
Use t (not z) when σ is unknown AND sample size is small (<30).
⚖️
Section 06
Hypothesis Testing
One-Sample Z-Test (σ known)
z_cal = (x̄ − μ₀) / (σ/√n)
Legend
x̄Observed sample mean
μ₀Hypothesized population mean (from H₀)
σ/√nStandard error of the mean
💡
Decision: Reject H₀ if |z_cal| > z_tab. Critical values: 1-tail=1.645 (5%), 2-tail=1.96 (5%).
One-Sample t-Test (σ unknown)
t_cal = (x̄ − μ₀) / (s/√n)
Legend
sSample standard deviation
dfDegrees of freedom = n − 1
Two-Sample t-Test (Independent)
t_cal = (x̄₁ − x̄₂) / √(s₁²/n₁ + s₂²/n₂)
Legend
x̄₁, x̄₂Sample means of groups 1 and 2
s₁², s₂²Sample variances of groups 1 and 2
n₁, n₂Sample sizes of groups 1 and 2
df= n₁ + n₂ − 2
Hypothesis Test Decision Rule
Two-tailed: H₁: μ ≠ μ₀ → reject if |t_cal| > t_tab
Right-tail: H₁: μ > μ₀ → reject if t_cal > t_tab
Left-tail: H₁: μ < μ₀ → reject if t_cal < −t_tab
🪤
Failing to reject H₀ does NOT prove H₀ is true — it only means insufficient evidence to reject it.
Error Type Definition Probability Controlled By
Type I (α) Reject H₀ when H₀ is actually TRUE α (significance level) Researcher sets α (e.g., 0.05)
Type II (β) Fail to reject H₀ when H₀ is FALSE β Increase sample size n
Power (1−β) Correctly reject a false H₀ 1 − β Larger n → higher power

Section 07
Simple Linear Regression
Regression Line Equation
Ŷ = β₀ + β₁X
Legend
ŶPredicted (fitted) value of Y (Y-hat)
β₀Intercept — predicted Y when X = 0
β₁Slope — change in Y for each 1-unit increase in X
XIndependent (predictor) variable
Slope β₁ and Intercept β₀
β₁ = Σ(xᵢ−x̄)(yᵢ−ȳ) / Σ(xᵢ−x̄)²
β₀ = ȳ − β₁·x̄
Legend
x̄, ȳSample means of X and Y
Σ(xᵢ−x̄)(yᵢ−ȳ)Sum of cross-deviations (numerator)
Σ(xᵢ−x̄)²Sum of squared X-deviations (denominator)
Correlation Coefficient r
r = Σ(xᵢ−x̄)(yᵢ−ȳ) / [√Σ(xᵢ−x̄)² · √Σ(yᵢ−ȳ)²]
Interpreting r
r = +1Perfect positive linear relationship
r = −1Perfect negative linear relationship
r = 0No linear relationship
⚠️
r measures linear association only. A curved relationship can have r ≈ 0!
Sign of β₁ and Relationship Direction
β₁ > 0 → Positive relationship (Y increases as X increases)
β₁ < 0 → Negative relationship (Y decreases as X increases)
β₁ = 0 → No linear relationship
💡
Sign of β₁ always equals sign of r (correlation).
🔬
Section 08
One-Way ANOVA & Chi-Square Test
One-Way ANOVA F-Statistic
F = MSB / MSW  = (SSB/df_B) / (SSW/df_W)
SST = SSB + SSW
df_B = k − 1  (between groups)
df_W = N − k  (within groups)
df_T = N − 1  (total)
Legend
MSBMean Square Between groups = SSB / (k−1)
MSWMean Square Within groups = SSW / (N−k)
kNumber of groups
NTotal number of observations across all groups
💡
If F_cal > F_tab: reject H₀ — at least one group mean is different.
ANOVA Sums of Squares
Grand Mean: x̄̄ = (ΣΣxᵢⱼ) / N
SSB = Σᵢ nᵢ(x̄ᵢ − x̄̄)²
SSW = ΣᵢΣⱼ (xᵢⱼ − x̄ᵢ)²
SST = ΣᵢΣⱼ (xᵢⱼ − x̄̄)²
Legend
x̄ᵢMean of group i
nᵢNumber of observations in group i
xᵢⱼj-th observation in group i
Chi-Square Test of Independence
χ² = Σ [(O − E)² / E]
E = (Row Total × Column Total) / Grand Total
df = (r − 1)(c − 1)
Legend
OObserved frequency (from the data)
EExpected frequency (calculated from totals)
r, cNumber of rows and columns in the contingency table
💡
H₀: variables are independent. Reject H₀ if χ²_cal > χ²_tab.
📉
Section 09
Time Series & Autocorrelation
k-Period Moving Average
MAₜ = (Yₜ + Yₜ₋₁ + ... + Yₜ₋ₖ₊₁) / k
Legend
MAₜMoving average at time t
YₜActual value at time t
kNumber of periods in the moving average window
💡
Forecast for next period = last computed moving average.
Simple Exponential Smoothing (SES)
Fₜ₊₁ = α·Yₜ + (1−α)·Fₜ
Legend
Fₜ₊₁Forecast for next period
αSmoothing constant (0 < α < 1) — higher α = more weight on recent data
YₜActual value at current period t
FₜCurrent period forecast
⚠️
SES does NOT capture trend. Use Holt's method when data has a trend.
Holt's Double Exponential Smoothing
Level:  Lₜ = α·Yₜ + (1−α)(Lₜ₋₁ + Tₜ₋₁)
Trend:  Tₜ = β(Lₜ − Lₜ₋₁) + (1−β)Tₜ₋₁
Forecast: Fₜ₊ₘ = Lₜ + m·Tₜ
Legend
αLevel smoothing constant
βTrend smoothing constant
LₜSmoothed level at time t
TₜSmoothed trend at time t
mNumber of periods ahead to forecast
Lag-1 Autocorrelation Coefficient r₁
r₁ = Σ(Xₜ − X̄)(Xₜ₋₁ − X̄) / Σ(Xₜ − X̄)²
Legend
r₁Lag-1 autocorrelation — correlation between consecutive observations
XₜValue at time t
Xₜ₋₁Value at time t−1 (one step back)
X̄Mean of the entire series
💡
r₁ > 0: positive persistence (high values follow high values). r₁ ≈ 0: no autocorrelation.
Method Best For Captures Trend? Key Parameter
Moving Average Stable (no trend) data No k (window size)
SES Stable / slowly changing data No α (0–1)
Holt's Double Data with trend Yes α, β (0–1 each)
